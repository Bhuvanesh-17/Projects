# 📌 Project Overview

RevenueLens is a complete Business Intelligence project that demonstrates the entire Data Analytics lifecycle—from data cleaning to interactive dashboard development.

The project analyzes sales transactions to uncover business insights related to revenue, profitability, customer behavior, product performance, shipping efficiency, and discount impact.

This project was built to simulate a real-world analytics workflow followed by Data Analysts in enterprise environments.

---

# 🎯 Business Objective

The objective of this project is to help business stakeholders answer questions such as:

- Which products generate the highest revenue?
- Which customers contribute the most profit?
- Which regions perform best?
- How do discounts affect profitability?
- Which shipping methods are most efficient?
- How are sales changing over time?

# 📈 Data Analytics Pipeline

## 1️⃣ Excel

- Data Cleaning
- Removed duplicates
- Handled missing values
- Standardized formats
- Prepared dataset for analysis

---

## 2️⃣ Python (EDA)

Performed Exploratory Data Analysis using:

- Pandas
- Matplotlib
- Seaborn

Analysis included:

- Dataset overview
- Data type validation
- Missing value analysis
- Statistical summary
- Correlation analysis
- Distribution plots
- Sales & Profit analysis
- Customer insights
- Product insights

---

## 3️⃣ MySQL

Designed the analytical database and implemented:

### Feature Engineering

- Shipping Days
- Profit Margin
- Discount Category
- Profit Status
- Date Features

### SQL Concepts Used

- Joins
- Aggregations
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Views
- Business Queries

---

## 4️⃣ Power BI

Created a Star Schema data model with:

### Fact Table

- Fact_Sales

### Dimension Tables

- Dim_Customer
- Dim_Product
- Dim_Date

### DAX Measures

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin %
- Average Order Value
- Sales Growth %
- Average Shipping Days
- Loss Orders
- Total Discount
